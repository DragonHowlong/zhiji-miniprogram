# 隐私政策（占位稿）

正式 URL 与法务终稿 **待用户拍板**。本页供小程序审核材料草稿与站内页同步。

## 运营者

由 **监护人/亲友（已满 18 周岁）** 注册的微信小程序个人主体账号运营；非未成年人本人账号。

## 我们收集什么

- 设备本地：草稿问卷、已发布问卷（含仅本地的 `ownerToken`）、作答昵称、匿名设备指纹、本机成绩缓存。
- 服务器（Cloudflare Worker 排行榜）：问卷 ID、昵称、分数、是否达标、匿名指纹、时间戳；出题人 token **仅存哈希**。
- 题目正文主要经微信分享 path 参数传递；现网 Worker **无**问卷正文存储接口。

## 我们不做什么

- 不做公开社交广场、不向陌生人推荐、不做动态信息流。
- 分享链路不包含出题人口令。
- 不在前端仓库放置管理密钥。

## 联系方式

占位：待运营者填写邮箱/微信。
